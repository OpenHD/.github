## About

OpenHD turns single-board computers and off-the-shelf WiFi cards into a long-range digital video link for drones, planes and other remote vehicles.
Instead of a regular WiFi connection it uses raw broadcast packets with forward error correction, so the link degrades gracefully rather than dropping out.
Alongside video it carries MAVLink telemetry and RC control, and works with ArduPilot, PX4 and QGroundControl.

## Repositories

| Repository | Description |
| --- | --- |
| [OpenHD](https://github.com/OpenHD/OpenHD) | Core: video, telemetry and wifibroadcast link for air and ground units |
| [QOpenHD](https://github.com/OpenHD/QOpenHD) | Ground station app with OSD and settings |
| [OpenHD-ImageBuilder](https://github.com/OpenHD/OpenHD-ImageBuilder) | Builds the flashable OpenHD images |
| [OpenHD-KernelBuilder](https://github.com/OpenHD/OpenHD-KernelBuilder) | Kernels with patched WiFi drivers |
| [OpenHD-WebUI](https://github.com/OpenHD/OpenHD-WebUI) | Web interface for configuration and recordings |
| [OpenHD-SysUtils](https://github.com/OpenHD/OpenHD-SysUtils) | System helper scripts |
| [OpenHD-RV1126-OS](https://github.com/OpenHD/OpenHD-RV1126-OS) | OS for RV1126-based air units |
| [Documentation](https://github.com/OpenHD/Documentation) | Documentation sources |

## Getting involved

New to OpenHD? Start on our [website](https://openhdfpv.org) and grab the latest image from the [releases](https://github.com/OpenHD/OpenHD/releases).
Most of the community lives in our [Telegram group](https://t.me/OpenHD_User), which is the best place for questions. You can also find us on [Discord](https://discord.gg/NRRn5ugrxH).
Bug reports, testing and pull requests are always welcome.
